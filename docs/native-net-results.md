Confirmed source integration problem: uncached user pages in the pinned kernel use Device nGnRnE, so uncached Normal DMA cannot be obtained merely by setting cached=false. No speculative kernel memory-attribute change was made. Captured complete FDT/reservation evidence and actual MDIO identities remain absent. Upstream board delays/reset/clocks are reference candidates only. A read-only collector and source/hash audit are delivered.

Incomplete: native GMAC platform initialization, PHY/link service, RX/TX driver integration, safe DMA mapping/cache integration, bounded inter-PD queues, runtime status ABI and actual network PD integration. Therefore no gmac-link/rawio image or fake success artifact is shipped. MDIO/descriptor cores and Rust wire/session library are preparation, not a completed driver. Full compiler rebuild reproducibility and DMA isolation are not demonstrated.
