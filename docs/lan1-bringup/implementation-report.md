# LAN1 bring-up implementation

The candidate combines the working WAN DHCP, GMAC and health ELFs with a WAN supervisor extended to display LAN1 results and a separate LAN1 owner. WAN fatal reports retain priority. The new owner has priority 103 and a 100 µs budget per millisecond. LAN2 remains in reset. Its root, configuration and endpoint BAR windows are absent from the LAN1 address space.

The owner sizes BAR2, reads PCI identity and TxConfig, and rejects an unexpected B51 signature. While mastering is disabled, it probes the unrolled inbound region's limit registers, checks mode, alignment, address width and programmed fields, and bounds enable polling. It uses explicit PCIe and DDR addresses. The software currently admits only below-4-GiB source and target extents.

B51 startup masks interrupts, stops RX/TX, waits for FIFOs, resets the MAC, exits OOB, waits for the shared FIFO, powers the PHY and executes the pinned patch. The PHY patch handshake and indirect OCP/EPHY operations have finite retries. The firmware version word at PHY parameter 0x801e must read back 0x0016. The driver applies B51 PHY and EPHY settings, restarts autonegotiation, selects a single RX/TX queue, disables RSS and checks descriptor mode. It uses the backup station address with a valid active-address fallback, writes the selected address back to the MAC and checks it. Both BMSR link/autonegotiation and MAC link status must agree.

Linux v6.12 selects rtl8125b-2.fw for RTL_GIGA_MAC_VER_63 and calls r8169_apply_firmware from rtl8125b_hw_phy_config. Linux can continue when the firmware is absent. This diagnostic requires the pinned patch and its handshake to succeed before DMA. The Realtek-authored DPDK method 51 implementation likewise has distinct MAC and PHY MCU paths. The candidate uses the Linux firmware instruction format, including the MAC-MCU/PHY access switch, and the Realtek method 51 EPHY register table. The first valid request ends submission after one reply. The driver pads Ethernet frames to 60 bytes, checks TX ownership completion and monitors controller errors. It resets and drains the controller, clears endpoint mastering, checks PCIe Transactions Pending, and disables endpoint and root decoding. Failed quiescence triggers a reset attempt and an enduring shutdown fault. The pool stays private and is never recycled in this boot. Physical link, actual inbound translation, ARP reception and wire delivery await the board trial.
