# GMAC0 preparation, not an integrated driver

`mdio.c` implements bounded Clause-22 read transactions with injected register/time interfaces. No live MMIO backend is supplied or invoked. Offsets/fields follow locked U-Boot `drivers/net/dwc_eth_qos.h` and `eqos_mdio_read` in `dwc_eth_qos.c`, commit 127a42c7257a6ffbbd1575ed1cbaa8f5408a44b3. This original implementation is BSD-2-Clause; no U-Boot code was copied. The caller must establish the actual CSR clock and choose its verified divider. Both elapsed time and iteration count bound busy polling, including a stalled time source.

Not implemented/qualified: board clocks/reset/pinmux/supply, PHY reset/autonegotiation, integrated RX/TX service, DMA pool and cache mapping, IRQ or polling scheduling integration, fault recovery. No link/rawio image is emitted. The protocol service is host-tested Rust library code, not a running network PD. Do not promote this directory into a claimed native Ethernet implementation.

Reuse audit: the project has no existing native NIC service. Published sDDF compatibility lists 5.10a/5.20, not RK3568's 4.20a; no drop-in compatibility established. The locked U-Boot glue and board DTS provide reference candidates, not measured runtime settings. Native integration must not initialize networking in U-Boot.

`ring.c` is an independently compiled/tested DWMAC normal-descriptor core, not a complete MAC driver. It provides one 16-entry ring, fixed 1536-byte buffers, bounded TX submission/reclaim and RX copying/rearm. TX pads with zeroes, clears buffers, checks capacity and ownership; RX rejects incomplete/context/error/invalid-length frames before copying and restores fixed software-owned buffer addresses. Each operation is bounded. Tests inject DMA status writes, not a device simulation. FCS inclusion is an integration input that must match the qualified MAC configuration. Both descriptor and data memory require the same verified Normal-NC allocation contract; callbacks must implement actual acquire/release DMA barriers, never empty functions on hardware. Ring initialization and RX preparation require DMA quiescence. Hardware tail/list registers, timeout/reset control, MAC/MTL, bus translation/cache maintenance and polling service are not implemented. No hardware backend or build-time admission path is supplied.

Bit positions/descriptor layouts are referenced from locked U-Boot's EQoS header/send/free-packet paths and Linux v6.1 `drivers/net/ethernet/stmicro/stmmac/dwmac4_descs.h` (GPL-2.0-only reference, not copied). The project implementation is BSD-2-Clause. The referenced file is cached with its provenance for offline inspection. Device ownership ordering is not established by volatile alone; the injected barriers are mandatory and deliberately unresolved for a live device until mapping/coherency qualification.
